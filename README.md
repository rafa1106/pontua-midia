# pontua-midia · branch `reels`

Vídeos dos Reels do @pontua.club em URL pública para a API do Instagram (o Make publica a partir de
`https://raw.githubusercontent.com/rafa1106/pontua-midia/reels/<arquivo>.mp4`).

Branch órfã de propósito: o `main` (artes e geradores) continua leve, e os clones da rotina e da Action
(`--depth 1` / checkout padrão) não baixam estes vídeos.

Cópias de publicação: H.264 High ≤4,5 Mbps, GOP fechado de 2 s, AAC 128 kb/s 48 kHz, `faststart`.
Os originais ficam no PC do Rafael (`05_reels_finais`).
